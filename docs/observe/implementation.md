# Implementation contract

[DESIGN.md](../../DESIGN.md) is the authoritative Go product specification.
[ARCHITECTURE.md](../../ARCHITECTURE.md) assigns package and state ownership.
[README.md](../../README.md) distinguishes completed gates from pending work.
[CONTRIBUTING.md](../../CONTRIBUTING.md) lists executable verification commands.

The preserved [source brief](source-design.md) is historical input. Its SQLite,
Tantivy and Rust details are not active Go implementation instructions. Corrections
belong in the English Go design; the source brief must remain byte-identical.
